# 校园网建设与管理 · Week3 实验

本工作区完成 EXP3 按手册顺序要求的三个固定任务：

1. 阅读混合材料并制作校园网办事指南。
2. 整理校园设备台账并生成分析图表。
3. 制作可搜索问答、可按地点筛选设备的本地服务网页。

> 所有学校、网络、通知、资产与报修记录均为教学模拟，不代表任何真实学校的情况。

## 六、使用与复核提示

- 复核时直接按“编号—文件—小节/条目”定位，例如 `03，第1页，M1` 表示 03 号 PDF 第 1 页 M1 小节。
- 不要修改或覆盖 source/ 下的任何原始文件；成果与过程证据分别放在 output/ 与 evidence/。
- output/任务3/校园网服务页.html 为单文件离线页面，用浏览器直接打开即可；任务3 证据中的“浏览器实测”使用本地 file:// 路径，无需服务器。
- 完成实验使用的是Codex-ChatGPT 5.6-sol.
